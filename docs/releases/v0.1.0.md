# mojo-inotify v0.1.0

**Released:** 2026-10-21 · **Commit:** `eb6f085` · **Previous:** first release

## What it does

Watch files and directories from Mojo with Linux inotify. One preallocated read buffer, events read in place, and a pollable file descriptor for an event loop.

## Highlights

- Draining 200k events takes 37 to 38 ms against 121 to 125 ms in Python: the loop runs at the cost of the `read` calls themselves.
- An `Event` is an 8-byte view into the buffer, no copy per event.
- All `IN_*` constants exported; names up to 255 bytes; moves keep their cookie.

## Known limits

- Linux only.
- Queue overflow (`IN_Q_OVERFLOW`) is not covered by the gate.
- A program that declares its own `read`, `write` or `mkdir` with other argument types will not build; see docs/design.md.

## Upgrade / run

```
git clone https://github.com/amarbaro/mojo-inotify && cd mojo-inotify && uv sync
mojo run -I src examples/quickstart.mojo
```
