## What it does

<!-- Stable description of the program. Carried forward from the previous note; edit only when the product itself changes.
     3 to 6 lines: what it is, who uses it, where it runs (URL/port/binary), how to start it. -->
Watch files and directories from Mojo with Linux inotify. One preallocated read buffer, events read in place, and a pollable file descriptor for an event loop.

## Highlights

- `mojo precompile` of a package that uses `add_watch` no longer fails.

## Changes

### Added
- Conda recipe (`recipe.yaml`).
- README install block, one example, and badges for CI, latest release and license.

### Fixed
- `mojo precompile` no longer fails on the recursive `CStringSpan.__init__` (the `as_c_string_span` call of `add_watch` moves into a helper); the gate now precompiles the package too.
