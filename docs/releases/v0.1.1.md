## What it does

Watch files and directories from Mojo with Linux inotify. One preallocated read buffer, events read in place, and a pollable file descriptor for an event loop.

## Highlights

- Builds on the Mojo 1.2 nightly as well as on Mojo 1.1.

## Changes

### Fixed
- Building with Mojo 1.2 (`1.2.0.dev2026102105`) failed with `existing function with conflicting signature`: the 1.2 stdlib declares libc `read` and `write` with its own argument types. The library now calls glibc's `__read` and `__write`, the same functions under names the stdlib does not declare (exported since GLIBC_2.2.5, on every x86-64 glibc).
